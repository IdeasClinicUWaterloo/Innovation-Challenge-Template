# Submission Guidelines


## Final Submission

Teams should submit a complete solution addressing the challenge objectives.


## Required Deliverables


### Project Documentation

Include:

- Problem understanding
- Proposed solution
- Design decisions
- Expected impact


### Prototype or Implementation

Depending on the project:

- Software prototype
- Hardware prototype
- CAD models
- Simulation
- Research results


### Source Code

Include:

- Source files
- Dependencies
- Setup instructions
- Usage instructions


## Presentation Materials

Teams should prepare a presentation explaining:

- Problem
- Solution
- Technical approach
- Demonstration
- Impact


Possible materials:

- Drawings
- Videos
- Animations
- Models
- Screenshots
